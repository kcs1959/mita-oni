# フロントエンド実装メモ

## Vue と Phaser の分担

- Phaser 4 は盤面（迷路・キャラ・視界）の描画だけを担当（`src/game/MazeScene.ts`）。タイマー・役割表示・十字ボタン・モーダルは Vue。
- Phaser は `/play` でのみ使うので、ルートごと遅延読み込みしている（Phaser 単体で 1MB 超）。
- `fps: { target: 60, limit: 60 }` で高リフレッシュレートのモニタでも 60fps に固定。

## 視界制限

- 盤面の 2 倍サイズの暗い板に、中心だけ透明な円を抜いた CanvasTexture を 1 枚作り、毎フレーム自分の位置へ動かす（「プレイヤー + 外円ごと移動」）。Phaser 4 の Mask フィルタより単純。
- 霧は完全に不透明ではない（盤面がうっすら見える Figma のデザインに合わせた）ため、相手キャラは視界の外では `setVisible(false)` にしている。
- 半径 x は `src/game/config.ts` の `VISION_RADIUS_PX`（ワールド座標。キャンバスは画面サイズに合わせて拡大縮小される）。

## 補間

- サーバーからは 30Hz でマス座標が届く。描画位置は目標位置へ指数的に近づける（`FOLLOW_RATE`）。2 マス以上離れたら瞬間移動。

## 入力

- 十字ボタンは `pointerdown` で 1 回だけ送信。押しっぱなしでは繰り返さない（長押し無効・連打で移動）。
- プレイ中に盤面をタップすると、役割の色（鬼は赤、逃げはシアン）の輪がタップ位置から広がり、450ms で消える。Vue のオーバーレイで表示し、移動入力は送信しない。
- 連続タップはそれぞれ表示し、アニメーション終了時・盤面の破棄時に消去する。`prefers-reduced-motion: reduce` では拡大せず 120ms のフェードに切り替える。

## ランキング

- 決着後にサーバーから届く `recordId` を `/ranking?role=&me=` に渡す。自分の役割のタブでだけ「あなたはここ！」を出す。

## Figma との差分

- スマホ縦画面のデザインを PC の全画面向けに再配置した（プレイ画面は盤面を左、HUD と十字ボタンを右に配置）。
- START ポップアップの「START!」ボタンは置かず、カウントダウン終了でサーバーが自動開始する。
