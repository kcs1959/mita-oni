# Mita-Oni design assets

Source: [Mita-Oni — 石橋俊デザイン訂正案](https://www.figma.com/design/pEJA8ksCNRXTaUAXWF5cM6/Mita-Oni?node-id=33-2).

- `route-home.svg`: route decoration, node `33:25` (342 × 363).
- `route-ready.svg`: route decoration, node `33:95` (342 × 400).
- `route-result.svg`: route decoration, node `33:770` (342 × 324).
- `oni.svg`, `runner.svg`: mascot artwork, nodes `33:36`, `33:42`.
- `radar-*.svg`: matching radar rings, nodes `33:65`–`33:67`.

Export geometry is preserved. At the user's request, the original frontend accents replace the Figma palette: gold `#FFC975` → lime `#C8F66C`, cyan `#85E2E3` → `#78E8F0`, coral `#FFAB9B` → red `#FF797E`; face details use the existing `#101728`.

Device status bars and home indicators belong to the phone mockup and are not reproduced in the web interface. Gameplay and the map guide use the existing Phaser renderer instead of static design screenshots. The existing `AmbientDots` space background is retained.
